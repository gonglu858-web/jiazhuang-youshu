# L2其他成员：最小固定路径分类方案

2026-10-28，接手master 7563050。用户要求开始下一步；本轮仅整理本地方案，未修改实现、编译或执行新诊断。方案不构成真实私密输入或完整L2放行。

## 1. 已有证据与目标

[上轮记录](Codex记录-L2成员v3单次诊断四成员-20261028.md)及[回执](证据/CodexL2成员诊断运行v3-20261028.json)显示累计4：两个FIXED_NODE、两个OTHER_IMAGE；成员创建时间和退出记录齐备，本次清理已确认。所有parent仍UNKNOWN，原normal累计恰2门槛失败，未开展传输。

现有[观察器v2](证据/CodexL2成员观察器v2-20261028.cs)Capture只对当前Job已确认成员查询映像路径，完成创建时间/Job复核后立即投影为FIXED_NODE或OTHER_IMAGE，再清空StringBuilder。原路径没有保存，不能从旧JSON还原，不能用旧PID重新查询而冒充原身份。

本方案只为下一次受控观察增加一个固定路径候选分类，不解决父链，不证明可信来源，也不豁免额外成员。无需新增Win32 API、进程枚举或文件读取。

## 2. 候选及定义

保留现有image字段和语义不变，另增每成员pathClass；新回执schema升级为codex-l2-member-job/2，旧/1证据与校验器原样保留。新消费端只接受/2，不把旧字段缺失修补成有效新回执。

| 固定输出标签 | 判定输入 | 证据含义 |
| --- | --- | --- |
| FIXED_NODE_PATH | 完整路径等于既有固定Node常量 | 只说明路径匹配，不是逐进程文件验签 |
| WINDOWS_CONHOST_PATH_CANDIDATE | 完整路径等于固定字面量C:\Windows\System32\conhost.exe | 仅为一个明确待证伪的路径假设，不证明真实微软文件、因果关系或父链 |
| OTHER_PATH | 成功捕获、但均不匹配 | 已捕获另一路径，具体内容不输出 |
| UNKNOWN | 未成功完成身份捕获 | 无可用分类，不补造 |

**候选依据与局限：** 此次选择conhost是针对“可能有控制台附带成员”的单一调查假设，不来自上轮路径证据，也未查询本机该文件是否存在。旧报告明确禁止先认定控制台宿主或安全软件，本方案维持该限制。不增加OpenConsole、任意安全软件或其他猜测词表；不能把候选名称写成已观察到的程序名。

比较固定为StringComparison.OrdinalIgnoreCase的完整字符串相等：不使用basename、包含、后缀、模糊匹配，不展开环境变量，不做GetFullPath/真实路径解析，不解析链接/短路径/设备路径。不同拼写形式即不命中。常量不从计划、CLI、环境或文件内容读入。

分类只在原Capture成功出口进行：原有IsProcessInJob、存活、两次创建时间及Job复核全部保留；同一个路径局部值用于image与pathClass，之后按既有方式释放引用。清空长度不保证托管内存安全擦除，不新增“零内存残留”承诺。失败或异常保留UNKNOWN及原失败状态，不为分类重开PID、延长观察或补查询。

## 3. 新旧事实严格分开

- CAPTURED+FIXED_NODE必须对应FIXED_NODE_PATH；CAPTURED+OTHER_IMAGE只允许候选标签或OTHER_PATH。
- 非CAPTURED只允许image=UNKNOWN、creationTime=null、pathClass=UNKNOWN，沿用既有状态语义。
- 严格枚举字段、类型和标签；缺失、额外字段、任意路径文本、不一致组合拒绝整份回执，不部分修补。
- root身份、成员容量16、事件容量128、创建时间/计数/事件/清理校验保持，不以候选标签放宽任何一项。
- identityCoverage只沿用原定义，不增加approvedMembers之类名称；parentEvidenceComplete、sourceChainComplete保持false。
- 即使两项均命中候选，累计4仍TREE_COUNT，originalNormalPassed=false、ok=false/exit1；诊断收集成功与自检失败同时如实存在。不能做“总数减去候选数”的通过判定。

## 4. 最小实施范围（下一节点）

新命名驱动/离线证据同步schema、pathClass严格验证与来源摘要。沿用v3的先保留ChildProcess、管道构造作用域、公共网络/进程阻断、时限/输出限额、一次执行、wx证据及清理不确定口径，不再触碰已关闭修正。新驱动在产物未生成/未审查前须默认只读且真实执行能力未就绪，不可复用旧二进制宣称新schema已验证。

## 5. 必需离线验收

1. 纯分类：固定Node、唯一候选、大小写对照、另一路径、空/失败状态；路径形状变体（用户目录同名、System32evil、SysWOW64、前后多字符、引号、空白、NUL、相对路径、环境变量、短/设备/UNC形式）不得误命中候选。无原路径回显。
2. 同一Capture链：用真实新源码配底层边界替身验证只读一次路径、原创建时间/Job检查先于输出、失败仍UNKNOWN、无新增OpenProcess或文件/网络操作。只做JS翻译函数的测试不能冒充C#实现行为通过；若尚无允许的C#执行条件，分列静态与模型，待编译后合成验证，不宣称动态覆盖。
3. 实际新驱动消费者：四成员含两候选仍exit1；缺字段/假标签/任意路径/不一致组合/旧schema全部拒绝；正常两Node对照可保持原normal语义，但L2未放行。
4. 泄漏反例：路径含合成秘密，最终JSON/错误只含固定标签；不得为日志排错额外保存原路径、文件名、前后缀、哈希或长度桶。
5. 守卫/来源/输出：复用受影响用例，证明源码/配置/产物漂移拒绝、公共网络进程拒绝、管道包装失败事实及有限收尾不回归、无回执不宣称清理。历史字节与两文档后缀核对。
