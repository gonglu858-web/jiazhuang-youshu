## 1. 三种事实分开，不再互相替代

| 层次 | 要证明什么 | 不能据此声称什么 |

| H 当前宿主 | 新驱动实际process.execPath是受审固定Node，程序及路径链、摘要符合锚点 | 不能证明PS1将启动同一程序 |

## 3. 验证顺序与每段停止点

### P0 新驱动先做离线准备与审查

先新增有版本的三层预检驱动及全合成对照，默认stdout、--out仅新路径wx写入。固定阶段入口，不允许调用方自报路径/摘要、任意脚本、skip/force或环境变量豁免。默认只执行H/F与环境元数据，不能默认连跑后续阶段。各阶段必须显示pass/fail/blocked/not-run，阶段通过不升级其他阶段。

先验证正常与必要失败出口：宿主/PS1/依赖漂移、环境响应缺失或歧义、策略阻断、进程超时/非零/输出超限、七场景报告不完整、传输少字段/错值/空串丢失、身份ACL失败、收尾守卫命中。使用实际新驱动、仅替换底层边界；保留独立离线兜底，不修改已审产品。源摘要/所有核验/收尾完成后形成唯一最终ok和exit，同源计数，覆盖实际摘要点；不重做已有身份安全测试。

新驱动未审查通过前不发起真实环境查询。

### P1 H/F与一次只读环境元数据查询，交付后停止

1. 先核对Git状态、来源、预期输出目标、当前宿主process.execPath与固定Node摘要/路径链。未知改动、链接、文件/摘要不符、输出目标已存在即停止；不启动另一Node来使自查变绿、不安装更新。
2. 静态核对PS1受审字节、固定常量与共用启动链，仅读取源码；不提取函数执行。H/F任一失败，环境子进程次数必须0。
3. 用固定PowerShell完整命令查询版本、有效执行策略和五个作用域、首选Node匹配事实；只读元数据，显式PSHOME必需模块初始化，使用既有受审查询形式，不包含PS1正文。禁止-ExecutionPolicy参数。不转储环境变量、身份、候选路径或认证缓存。新schema严格验证字符串类型、枚举、作用域唯一性、字段集合，不能沿用版本正则的隐式类型转换。
4. 仅记录PATH候选数量/首选匹配布尔，绝不执行搜索到的候选；无法解析元数据不能靠历史结果补齐。
5. 无论环境允许与否，本段输出结果后停止，身份/ACL、动态PS、DPAPI/UI全部not-run。Restricted或有效策略/来源不确定时标L=blocked；已知相同环境曾拒绝-File且没有明确环境状态变化依据，不重复尝试。

“此前Restricted”不是当前实测。元数据返回非Restricted也不自动证明脚本可运行：AllSigned/RemoteSigned仍可能涉及签名/来源限制，策略作用域可能不同。环境若本来存在Process级Bypass等值须如实披露，不能由工具启动参数注入或据此直接宣称允许。拿不到确定的自然允许条件时保持blocked。不能为完成测试换宿主/账号、改策略、解除阻止标记或改文件位置规避策略。

### P2 L1：允许环境下运行实际PS1七个合成场景，交付后停止

仅在P1通过且该固定宿主环境**本来允许受审脚本执行**时，使用固定PowerShell：`-NoProfile -NonInteractive -File <受审PS1绝对路径> -SelfTestSynthetic -SelfTestScenario <固定场景>`。七场景仅N1_SAVE、N1_ECHO、N2_DECL、N3_FILE、N4_DRIFT、N5_STARTFAIL、N6_TRANSPORT；完整参数向量需在新驱动中逐项白名单，不能接受任意场景或SelfTestNodePath。

逐场景一次、顺序执行；结构完整、场景对应、断言总数>0/失败0、退出0、所需实际计数符合契约才算该场景通过。任一失败/超时/策略拒绝，后续场景not-run并停止，不补跑不同写法。N1的保存路径仍使用PS1内置底层替身，不调用真实store；七场景均不打开窗口、不查询身份ACL、不运行DPAPI、不创建私密文件。

这一步补的是PowerShell语义运行，不是实际OS文件锁与启动验证。SelfTestCheck单独exit0不能替代这七场景，AST解析或Node模拟也不能替代固定-File运行。

### P3 L2：一次真实合成参数回显，交付后停止

P2全通过后才启动固定PS1的`-SelfTestTransport`分支，省略SelfTestNodePath（使用内部固定值），其它参数是预先冻结的合成向量。固定参与者槽位1、synthetic轮次、虚构来源时间/摘要、虚构文件名及路径；没有账号明文、真实编号、口令或真实私密目标。含空格、引号及空值的准确样本/预期数组在驱动准备时写死并审查。

使用已有Get-StoreArguments契约：基础18项，加server-time-iso对为20项；Node启动另有-e与代码两项，总22项。PS1回显JSON应为**恰20项数组、逐索引字符串精确相等、顺序一致**，退出0、stderr无意外、无截断才通过。空值必须保留；不以只比较数量或拼接字符串通过。仅公开计数/匹配布尔，原始参数输出驻内存。

此时实际执行Test-FixedNodeBinding、同一句柄持有期间摘要核对和Start-FixedNode的selftest-echo分支，真实Node只回显argv，不执行参数中作为文本的虚构存储脚本，不调用protect或访问私密根。真实UI前分支与save-protect尚未运行，不能写为“UI前链/真实保存已通过”。不修改真实Node制造漂移、不做文件替换攻击实验。

注意现有回显路径先ReadToEnd再WaitForExit，内部5秒等待不等于完整读取有界。新外层runner必须提供总超时与128KB输出限额，并在启动前具备只针对本轮进程树的收尾能力；不能仅杀PowerShell而遗留Node。若现有受审能力不足，先停止提出限定runner方案，不用无限等待或批量按名称杀进程。实际可用的有界runner是执行前置，不能留到发生超时后再解决。

### P4 目录/身份只读预检，独立一段，完成后停止

H/F/L通过后再恢复真实store只读路径：先检查约定私密根存在、路径无链接，分配一个新synthetic目标名仅作不存在性预检；再查真实身份、Git未跟踪/忽略、icacls本进程契约及根ACL。沿用旧A中的真实受审store/local-tools/native-exec调用，不传假ACL，不读取/枚举已有密文，不创建/修复目录，不修改.gitignore或权限。

正常业务查询预计5次：whoami1、Git2、icacls2；环境查询在P1另记，准备阶段Git也单列；真实次数不得写死。缺根/目标已存在/链接/身份编码不确定/ACL未知或不合格即停止，后续查询不执行。whoami非ASCII继续保守blocked，不能借icacls编码契约放行。

阶段结果分别保留。只有H/F/L和P4各自通过、当前来源未漂移、守卫意外0，才记“新版只读预检通过”；旧A历史仍保持blocked。跨阶段源/环境变化要使依赖结果失效，不能把不同环境的通过拼起来。无变化则复用证据，避免机械重复。

## 4. 通用执行与失败约定

- 每段固定程序、完整参数、项目cwd、shell=false、windowsHide=true；只删除子进程NODE_OPTIONS，不修改父进程/系统环境。无公共任意spawn或命名管道能力；准备阶段网络/公共进程守卫必须在业务装载前安装。父Node守卫不等于PowerShell及孙进程已被网络隔离，后者只允许钉定脚本/参数，证据如实披露，不声称系统级沙箱。
- 查询单次≤10秒、128KB，P1/P4各≤60秒；PS七场景每次≤10秒、总≤90秒；传输段外层≤15秒且有已审本轮进程树收尾。实际计数记录attempted/completed/failed、状态/信号/超时/字节限额；预期反例失败与业务意外分开。禁止超时自动重试。
- 只允许显式登记探针从意外计数中排除，初始化、摘要和收尾中被catch者都计入；任何意外最终失败。成功0，环境/策略不确定阻断2，断言/意外/收尾或证据保存失败1；报告与真实退出码一致，宿主显示差异单列。
- 缺失、状态非预期、stderr、Buffer/严格解码/JSON结构失败均固定标签停止；只记录阶段和净化原因，不输出原始stderr、身份/SID、ACL、完整账号或密文。不得以“查询完成”冒充“校验通过”。
- --out已存在拒绝覆盖，不换名循环尝试；只清理由本轮确实创建并登记的临时文件，测试与清理分开，不清缓存/旧文件。遇文件写锁先停止分析，不换名或通过index/checkout绕过。
