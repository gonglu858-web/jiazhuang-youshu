## 5. 执行接口与权限

拟沿用已核对指纹的公共CLI 3.8.4，以固定Node、参数数组、`shell:false`调用。认证仍走既有受审宿主；秘密不写进参数/制品/日志。本次未安装软件，不新增IAM授权/API Key。

本包写接口统一使用官方 **tcb / 2018-06-08 / ap-shanghai**。此前元数据查询的旧 flexdb 路由不作为写失败后的自动替代。本轮已真实通过tcb ListTables含隐藏表读取；CreateTable/UpdateTable尚未调用。

| API | 本包用途 / 权限事实 |
| --- | --- |
| STS GetCallerIdentity、TCB DescribeEnvs/DescribeEnvInfo | 已真实读取并匹配身份、固定环境与AppID；执行前重验 |
| DescribeBillingInfo、DescribeEnvAccountCircle、DescribeQuotaData、DescribeBaasPackageList、DescribeCreditsUsageDetail | 本轮只读已调用；不产生购买授权 |
| ListTables、DescribeTable、DescribeDatabaseACL、DescribeSafeRule | 执行前/后元数据及规则核对；ListTables已实测，后3项本轮未实测，不把它们记成已获权限 |
| CreateTable | 待确认后仅建11个空集合；请求内携带 PermissionInfo.ADMINONLY |
| UpdateTable | 待确认后每次仅含1个CreateIndexes，最多13次；不允许DropIndexes |

`ADMINONLY`是数据库客户端访问规则，不是给操作人新增管理员，也不是把管理端身份或云函数权限物理限制在11个集合内。当前CAMRole能只读不证明它能创建；本轮没有取全量IAM策略或写入试权。第一次批准内创建若被拒即停，不授新权限、不换高权限账号重试。用户确认允许做，与腾讯云实际允许做是两回事。

官方[CreateTable](https://cloud.tencent.com/document/product/876/127968)支持同一创建请求带 `PermissionInfo:{EnvId,AclTag:"ADMINONLY"}`。采用此方式减少“先创建、再改权限”的间隔；不能宣称已实测原子权限保证。每个集合创建后立即核对规则，规则不符则停止，无数据写入、无测试函数启用。未预授权额外改规则进行补救。

[UpdateTable](https://cloud.tencent.com/document/product/876/127964)使用 `MgoKeySchema`对象、`MgoIndexKeys`数组、Direction字符串`"1"/"-1"`与布尔MgoIsUnique。[管理SDK文档](https://docs.cloudbase.net/api-reference/manager/node/database)提示已存在索引可能先删后建、批量索引可能部分成功，因此禁止对既有索引盲发创建。本包不使用把任意查询异常当成不存在的 `checkCollectionExists/createCollectionIfNotExists` 帮助方法。
