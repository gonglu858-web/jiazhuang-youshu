## 关键设计事实

- 驱动模块不 import child_process/net/http 等任何公共入口（证据内有源文检查）；spawn/等待/kill/来源摘要/回执全部由 boundary 显式提供——本轮全部为替身，真实产物不存在时绑定与运行均拒绝（ARTIFACT_NOT_BOUND / PE_* / PRODUCT_WIRE）。
- 绑定摘要来自提供的产物字节；本轮绑定对象为合成 PE32+ 头像（替身自测），**不存在真实产物摘要**，不得解释为已产出真实 exe。
- 驱动失败场景中 runner 把采集到的 facts 附着在拒绝错误上（e.facts.failure 分类：SPAWN_FAILED/TIMEOUT/STDERR/OUTPUT_LIMIT/CLOSE_UNCONFIRMED），失败类别可被审核逐项核对。
- fullRunOrder 与敏感性是**源文顺序验证**，只证明源码中表达式唯一且按序出现，不证明 C# 编译语义或平台行为。
- 编译配置工具事实（csc/mscorlib 等 SHA）为历史事实沿用，本轮未再次核对环境文件；pending 字段写明完整Run可执行夹具不在本配置、不因配置存在获得编译或运行批准。
