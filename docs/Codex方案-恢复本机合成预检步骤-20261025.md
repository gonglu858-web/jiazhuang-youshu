## 2. 先准备一个新的A阶段驱动

建议路径：`docs/证据/Codex本机合成预检恢复A-20261025.cjs`，结果使用同前缀的新JSON；实际执行日变化时用实际日期，路径已存在就另用新版本。**本方案没有创建这些脚本或结果。** 默认stdout、--out仅接受docs/证据下约定前缀且不存在的JSON，wx排他创建；输出路径不合规应在任何系统查询前拒绝。

不得直接重跑[旧预检v4](证据/Codex本机合成验证预检v4-20261024.cjs)：其fea22e0源码锚定和公共spawnSync接线均已过时。也不修改旧脚本/JSON，不能只替换旧摘要使其通过。新驱动不调用buildReal/prepareReal，不生成登记包。

新驱动必须先完成源码检查和底层全合成对照，再做一次实际A运行：

1. **固定来源。** 以68d379e tree为已审产品依据，列出实际装载依赖的字节数及SHA-256，写死受审预期值，运行前逐文件核对；不能从当前工作树现算一个摘要再当作预期。store/local-tools/native-exec/decoder/dpapi-scripts、使用的守卫/装载辅助均包含。PS1/打包器仅核对保护，不装载执行。AGENTS既有修改单列，不纳入产品批准。
2. **固定能力。** 产品代码不改，复用真实store/local-tools/native-exec；不注入假ACL读取器或替代解析器。若用既有模块装载辅助接线，明确披露：来源字节真实，A阶段只读能力封装转发到真实OS；这不是OS替身测试。产品可见的能力只能转发本轮whoami、两个Git目标查询、icacls根探针/私密根查询。spawnProgram、connectNamedPipe、PROTECT/UNPROTECT在A阶段调用即阻断记意外；不得因产品具备这些能力而在A放开。
3. **环境查询单独固定。** 现有native-exec只接受受审DPAPI脚本，不能为查环境给产品增加任意PowerShell接口。新驱动用不导出的、无调用方脚本参数的固定只读查询函数，完整脚本常量和固定程序/参数/选项先审核；仅查询版本、执行策略和首选Node匹配事实。它不是被拒PS1正文的替代运行路径。
4. **全程守卫。** 私有OS引用仅在封闭受限能力内捕获；公共cp、http/https/fetch/tls/dns/dns.promises及Socket连接默认阻断。守卫在产品装载前生效；初始化、查询、摘要读取、收尾期间所有非显式探针命中均计意外，含被catch者。A不允许命名管道，也不启动业务子脚本；唯一PowerShell子进程为固定只读环境查询。
5. **限制与事实。** 固定exe、cwd项目根、shell=false、windowsHide=true、删除子进程NODE_OPTIONS，每次10秒/128KB；先检Buffer/状态/信号/字节数，再解码。外层A总预算60秒，按剩余预算缩短单次等待或停止，不以预算不足为由启动下一命令。每次尝试、失败、退出状态均记账，不能只计成功或硬编码数量。
6. **合成敏感性。** 新驱动至少验证：正常；来源漂移/目标已存在写前停止；查询失败/超时/不确定编码/ACL拒绝；装载前或摘要读取期间被catch意外使最终ok=false/exit非0。只替换OS与FS边界，不修改受审产品。最终守卫快照在所有核验及摘要读取之后。失败分类和真实最终退出码同时断言，不重做B2/B3整套历史验收。

正常A业务查询预期6次：环境1、whoami1、Git ls-files/check-ignore各1、icacls根探针/私密根各1。进程内principal及契约缓存防重复。实际次数以记录为准；静态来源保护若使用额外固定Git命令，单列准备核对计数，不藏入6次、不拿预计数替代实测。任一步失败不跑后续查询。

环境查询只输出固定结构的版本、策略、候选数量和匹配布尔，采用明确的UTF-8输出契约并严格解码；不将icacls编码契约套到PowerShell，也不输出原始候选路径或错误内容。只对子进程本次输出作设置，不改系统代码页或持久环境。结果中把“阶段实际执行状态”和“后续就绪状态”分列：A结束时B/C/D均未执行；Restricted则另记UI就绪状态blocked，不把未运行写成已失败的UI测试。

## 4. 失败分类和不循环规则

- `PSR_NATIVE_CONTRACT_BLOCKED`：当前输出无法建立受审icacls通道契约，包括全ASCII/歧义等；保留blocked，不改代码页、不试另一编码直到通过。whoami非ASCII继续独立阻断。
- `PSR_NATIVE_DECODE_UNCERTAIN`或命令失败/超时：仅记录固定分类和步骤，不输出原始stderr、身份或ACL，不重复原命令、不换宿主试图绕过。
- `PSR_PRIVATE_ACL`：保留“主体不允许或解析不确定”的边界，不能凭该总错误宣称权限过宽/安全。可以在已有内存输出上用受审解析器分述固定数量，不额外查询、裁掉行或扩白名单。需修复时另立精确任务。
- 根缺失、链接、目标存在、Git跟踪/忽略不合格：停止，不创建/修复根、不修改.gitignore或ACL、不删除既有文件。
- 策略Restricted：只说明C阶段不可执行，不启动PS1，不加Bypass，不复制PS1正文到-Command执行。若环境查询失败，不以历史Restricted代替当前结果。
- 任意非探针能力命中：A=fail、最终exit非0，即使其他检查通过；错误信息固定净化，不回显捕获对象或stack。

一轮仅一次实际A尝试。失败后报告已证事实、卡住步骤和下一项最小处理；需要代码/权限/系统变更时停止提出方案，不自行扩修。基础环境变化后重跑也要新证据，不覆盖失败记录。
