## 3. shell 辅助路径不通过：已造成证据文件与入口报告脱节

定位：`docs/证据/WorkBuddyShell核对-20261006.sh:36–40`、`:61–67`。

处置已确定：停用此 shell 文件，不删除、不继续完善它，不重跑它。后续如宿主 spawn 失败，单一入口如实记未完成，由 Codex 决定是否需要单独、独立编号的新验证；不把一次失败扩成多条自动补跑链。

### 单一入口的使用边界

它的 main 写固定同名汇总，runId 使用秒+pid，runOnce 会删除同编号旧结果。因此“任何用法都不会覆盖历史文件”仍过强。本轮通过范围为审查实际采用的**唯一编号+独立汇总包装调用**，不包括重复 runId 或重复直接运行 main。保持当前源文件，只需在交接中明确有效运行方式，不再扩展工具架构。
