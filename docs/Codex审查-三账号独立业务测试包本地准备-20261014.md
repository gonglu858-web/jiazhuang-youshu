## 2. 必修缺口与闭合标准

### R1 [P1] checkDir信任制品自报清单，不能证明完整性、来源或动作范围

位置：`miniapp/scripts/package-business-test.cjs:504`（checkDir）。

它只验证schema和清单内文件的自报长度／哈希，没有从独立受审来源及严格计划重建预期清单，也不校验计划摘要、变换结果、模式及精确文件集。

独立复现：

- C02：目录只有schema、空files和空closePackage.files的manifest，返回ok=true、0文件。
- C03：E候选的EXECUTE_ALLOWED加入reassignSchedule，同时更新manifest内该文件的哈希和长度，原planDigest不变；check仍ok=true。

要求：校验完整计划、固定文件集、独立来源、精确变换及摘要；拒绝缺项／多项／重复项／越界路径／错模式。不能只把清单再哈希一次。关闭包应可单独验证，开启部分损坏或过期不妨碍核对关闭包。保留正常候选、关闭包及兼容入口的正向对照。
