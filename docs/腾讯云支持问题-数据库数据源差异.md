## CLI 实际接口与参数

本机安装包只读检查显示，`cloud_db_read_struct` 使用 `cloudbase.commonService("tcb", "2018-06-08")` 调用 `ListTables`，参数为 `EnvId`、`MgoOffset`、`MgoLimit`；`cloud_db_read_doc` 通过同一服务调用 `QueryRecords`，最终参数包括 `EnvId`、`TableName` 和查询条件。两个 CLI 工具的公开输入均没有 `Tag`、`MongoConnector` 或数据库实例选择项，实际请求也没有传网页中的 `flexdb`／`tnt-efictvp6`。腾讯云[官方 `ListTables` 文档](https://cloud.tencent.com/document/product/876/127965)列有可选的 `Tag`（FlexDB 实例 ID）及 `MongoConnector`，但未说明只传 `EnvId` 时的默认数据源。我们因此无法证明 CLI 返回的集合与网页所选项属于同一个数据库。
