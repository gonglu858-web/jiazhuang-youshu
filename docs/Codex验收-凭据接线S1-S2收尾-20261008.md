## 4. 结论边界与后续维护注记（不重开返修）

1. `attempted=true`表示尝试启动，不等于进程正常运行或请求到达平台。启动错误下保留spawnFailed与空退出码是正确的。
2. 超时/超限时kill请求可能未确认，报告保留terminationConfirmed=false、后续停止；不要求把未知改成“已终止”。
3. 目录检查不是操作系统文件隔离或并发文件变更防护。代码与CLI均沿规范化cwd向上检查；如果profile自身存在路径别名/联接，不能仅凭字面包含关系概括“真实路径必然在profile内”。本轮已测普通profile和目标祖先污染，不泛化为所有Windows路径形态。它不改变已复现S1漏检路径被封堵的结论。
4. safe replay 的进程兜底是当前代码路径的运行时检查，不是任意程序的系统级防火墙。对当前脚本已核对的调用范围足够，不能推广为任意新增代码都零网络。
5. 证据称完整正向链通过，是合成凭据与进程替身下的接线结果，不证明腾讯云接受了真实签名、IAM、数据库记录或平台事务。
