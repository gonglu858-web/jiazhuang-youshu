日期：2026-10-08。性质：本地实现任务与验收标准；不是取得真实凭据或执行云查询的指令。

## 1. 目标与本轮边界

把现有 SDK 只读编排器中尚未实现的 `fetchTemporaryCredential` 接到固定公共 CLI 的 `secrets get --json`，形成可供 Codex 审查的候选实现。先用合成登录资料和被拦截的传输验证公共命令，再接线；默认入口仍只做本地检查。

本轮 WorkBuddy 只做本地代码、离线核验、交付记录。不运行使用现有登录态的 `secrets get` 或真实 `--read-only`，不读取现有认证文件内容，不联网、不安装、不初始化、不创建资源、不部署、不启用入口、不处理 A/B/C。不得用真实凭据排查实现问题。

Codex 审查通过后，另行接续已有登录及只读核验授权。取得凭据、身份关联、数据库记录核对是不同阶段；任一阶段成功都不产生写入许可。

## 4. H1：先验证真实公共 secrets 命令的离线契约

使用固定 Node + 原始 `bin/tcb` + 原始 bundle，在新建的合成 profile/cwd 中执行。沿用已审查证据的受控传输思路：所有实际网络出口与外部子进程先拒绝，只对核对过的请求提供合成响应。不得抽取 webpack 内部函数代替公共命令执行。

- 合成网页登录资料只存在于本轮新目录；按固定源码核对格式，禁止复制、读取、改写真实 auth.json。工作目录及其配置发现路径不得落到真实项目认证配置。
- 先覆盖有效临时登录态、无登录态、永久密钥、过期但可刷新、不可刷新、服务未初始化六类。失败类不要求相同码，但须确认没有意外放行、真实网络或初始化。
- 保存净化的请求目标/action/次数与本地文件操作类别，区分公共命令调用数与底层请求数；不保存请求体、请求头、token、签名或登录资料。
- 识别前轮被拦的外部子进程用途：只记录合成条件下的程序/净化参数和是否必需；不得为完成主命令而直接解除全部拦截。
- 明确设置 `TCB_DISABLE_REPORT=1`；对遥测、`InitTcb`、登录浏览器、未核对外部程序及其他未知请求保持阻断。服务未初始化必须停止，不能顺便开通。
- 输出实际 JSON 结构、提示包装和过期时间格式的结论；用标记相等判断证明命令输出来自该合成登录态，不把合成明文写入交付报告。

H1 无法完成时保留生产硬停止点，交付已证实事实与最小缺口。不要一边写“附加行为未知”一边自动放通真实获取。相同环境失败路径排查两轮仍无进展即停止并报告，不反复试装或重跑。

## 5. H2：固定获取宿主与私有内存输出

H1 完成后实现候选宿主，仍不执行真实获取。

1. 固定命令参数为 Node + `[cliEntry, 'secrets', 'get', '--json']`；`shell:false`，关闭 stdin，不接受用户拼接的参数。获取阶段不传 `--env`，不把 CLI 回显 envId 当归属凭据。H1 如发现必要公共参数差异，给出具体证据再调整。
2. **区分两个目录用途**：获取阶段将官方 CLI 指向上述既有登录 profile，使用无项目配置的新 cwd；后续身份查询使用另一套全新、空认证状态的隔离 profile，仅注入取得的三字段。不得将原 profile 复用于后续三条 API。
3. 环境构造继续大小写无关清除身份覆盖、XDG、代理与 Node 注入变量，再设置明确的 profile/home/config 路径、地域、CI 与 `TCB_DISABLE_REPORT=1`。避免 HOME/APPDATA 与 USERPROFILE 指向不同身份源。我们自己的代码仅核对路径，不读取现有 auth 内容；官方 CLI 自己访问登录缓存须如实区别记录，不得称整个进程“没有读取登录态”。
4. 复用已验收 `spawnBounded` 的 55秒总限时、stdout+stderr 合计1MiB、exit后2秒close宽限及晚到error处理，不自建第二套生命周期控制。超限/超时/异常/非零退出/close未确认，均在解析成功之前拒绝，不自动重试。终止未确认时不得启动下一阶段。
5. 原始 stdout/stderr 仅在私有有界内存流转；不继承到终端、不重定向到文件、不放进 Error/message/stack/cause、测试快照、报告或调试日志。宿主对外只返回解析后的私有快照与重建的固定诊断字段。上层不能把包含原始输出的整个执行对象序列化。
6. 复用严格凭据解析：三字段非空字符串、临时标记严格 true、合法未来时效且起点剩余至少5分钟；拒绝多根、截断、永久密钥、无效日期与缺字段。`token` 只在 `buildSdkConfig` 映射为 `sessionToken`。不收集 refreshToken，不增加刷新器，不再获取第二份凭据。
7. 获取开始前校验固定安装指纹。官方 CLI 可能进行自身登录缓存更新：本轮只核验合成路径，未来真实运行须在审查中列明已知行为；不得由自有脚本直接迁移/删除/修复登录缓存。失效登录只报告停止，不自动发起登录或打开浏览器。

附加行为的执行边界须写清：离线拦截器证明了什么、候选生产宿主实际控制了什么。若生产未实现请求级拦截，只能称固定版本及已核验路径，不能称未知请求已被技术阻断；仍未知的实际执行分支列为真实运行阻断项。**本任务不要求开发通用出网防火墙、签名器或替换 CLI 的内部认证协议。**

## 6. H3：同批接线与报告事实

- 默认模式只检查本地，不启动凭据命令；坏参数亦零获取。显式 `--read-only` 的候选接线路径才可进入获取。WorkBuddy 本轮不得在真实登录环境执行该模式；测试须使用合成依赖或隔离合成 profile。
- 一次取得快照后，按原顺序 STS → DescribeEnvs → DescribeEnvInfo → SDK；失败即止，保留未执行阶段占位。三条 API 子进程也设置关闭遥测，不继承原登录 profile，不再次调用凭据获取。worker 私有 stdin 仍只传一次并关闭。
- 获取成功只记 `FETCHED`，不能立即 `sameBatchCredential.proven=true`。只有真实受审宿主、同一快照传递、三阶段身份关联、SDK规定读取及父进程时效检查都满足时，才可形成限定为“本次调用链”的完成证据。任何模拟凭据、CLI响应、进程或SDK传输注入都不得升级为生产证明。缺目标/缺记录的整体核对继续 INCOMPLETE；不能为变绿而找别的用户代替。
- 本地能力字段与运行证据分开：`credentialFetchHostImplemented` 表示实现存在；离线公共入口证明注明命令范围、固定指纹与证据引用；`productionSameBatchObserved` 或等价字段只有真实执行结果才能成立。不能将固定布尔常量或测试 `deps.proven=true` 当作生产证据。
- 获取命令自身可能已经做认证查询，因此获取失败不再笼统写“未发起任何云查询”；改为“未进入后续身份关联/数据库读取”，另记获取子进程是否尝试。启动子进程也不等于请求已到达平台，未知请求数不得填0。
- `refreshed:false` 若保留，明确只指**取得快照之后**；获取过程内部刷新未观测时标未知，不推断未发生。不得声称清理 JS 引用等于内存已安全擦除。
- 所有分支 `writeAuthorized=false`、`productionCallerVerifierImplemented=false`。不得接 P4 `verifyCaller`、生成 approval/生产允许名单，或把腾讯云身份等同微信管理员身份。
