## 1. 确定的受测对象与调用链

受测源码：[观察器 v3](证据/CodexL2成员观察器v3-20261028.cs)，SHA-256 `722d28e9e2f145d9bcf4e00fb82ee4837ec4b365d53bdd86b4472a6228fd9019`。只读关联调用：[辅助层 v2](证据/CodexL2成员诊断辅助层v2-20261028.cs)，SHA-256 `0e67ee083cdcbe67773362ff62f4ee766e6cc083c4ed2a7f26e6eab696cba2ce`。本轮现场摘要与既有编译记录一致。

真实调用为辅助层创建观察器 → Root → 循环 Poll → finally 中 Stop → Json。观察器内部为 Drain/Census → Capture → ClassifyPath；Stop 复查创建时间、Job归属和退出状态，释放自有成员句柄与完成端口。外部传入的根句柄由辅助层释放，观察器不拥有它。

本轮范围仅为观察器的合成验证。辅助层含真实进程启动与终止、文件和管道操作，**不得进入测试程序集**。因此本方案不验证辅助层完整运行、Job真实隔离或系统通知可靠性，也不解释四成员的实际来源。

## 2. 复用方法：固定边界替换，禁止重写算法

保留历史 v3 源码原字节。后续另建准备器，在核对完整 SHA-256 后生成测试副本，仅允许三个确定变换：

1. 类声明增加 `partial`，供独立固定夹具访问该类私有类型及分类函数；不改变任何成员可见性。
2. 将连续 10 条 DllImport/extern 声明替换为同签名的受控转发方法，调用同类中的合成边界：CreateIoCompletionPort、GetQueuedCompletionStatus、Associate、QueryIds、OpenProcess、IsProcessInJob、GetProcessTimes、QueryFullProcessImageNameW、WaitForSingleObject、CloseHandle。
3. 仅 Drain 中那一个 `Marshal.GetLastWin32Error()` 改为合成边界的错误码读取。其他 Marshal 分配/释放与内存布局操作保留，操作对象只限当前测试自行分配的缓冲区。

所有替换要求精确锚点与预期命中数。输出应附变换清单；移除白名单替换后可还原原始字节并与 v3 比对。ClassifyPath/Capture/Root/Slot/Drain/Census/Poll/Stop/Json 的其余字节不变，禁止整文件换行规范化。不得以新写一份等价算法代替真实方法，也不得复制业务判断进夹具来决定返回值。

夹具放在另一新命名 C# 文件，同一个 partial 类中提供边界和极小测试入口；分类入口直接调用原 ClassifyPath，其余尽量走原公开 Root/Poll/Stop/Json。无需反射修改业务状态。伪 PID、Job、句柄均为固定合成数值，绝不交给系统 API。

## 3. 合成边界与实际记账

- 每场景独立、按顺序消费预设调用脚本；核对 API 名、参数、句柄归属、缓冲区尺寸、超时等。未知调用、超次数、未消费预期调用均计失败，不默认返回成功。
- 图像查询仅把合成路径写入传入 StringBuilder；QueryIds 仅写测试自身分配的缓冲区。禁止读文件、获取真实 PID、调用 Process/网络/注册表/证书 API，禁止动态装载或反射调用原生能力。
- 句柄账本分别记录端口、自有成员、借用根句柄。CloseHandle 的成功/失败/抛错由场景配置，实际调用记录决定账本，不从对象自报 HandlesClosed 推导关闭次数。
- 异常即使被原 Poll/Stop 捕获也保留在边界账本，区分预期故障与意外调用；最终 verdict 在全部断言、清理核对与报告数据准备后形成，ok 与退出码同源。
- 每场景捕获预期异常并执行有界清理；意外异常停止该次测试，不改结果、不自动重试。报告不输出合成路径原文以外的系统信息，更不收集真实编号或凭据。
