# 装修进度验收 · 本地交互原型

## 怎么打开

- 服务运行时，在制作这份原型的电脑打开 http://127.0.0.1:4173 。
- 电脑重启后，在本文件所在文件夹双击 `start.cmd`。它使用本机已有的 Node 环境启动原型，并打开浏览器，不安装新软件。
- 如果打不开，把情况告诉我即可，无需自行反复安装或修改设置。
- 这是本机入口，手机或另一台电脑不能直接通过该地址访问。

## 建议先试这七条流程

### 1. 师傅申请 → 管家提交 → 主业主确认

1. 选择“师傅”，在师傅下拉框选择“孙师傅 · 拆改工”。
2. 进入“阶段验收 → 拆改阶段”，应看到第 1/11 阶段和 5 项已确认检查清单。
3. 点击“施工完成，申请验收”，填写施工完成说明，并用“拍摄照片”模拟选择至少 3 张图片。视频可以补充，不能代替这 3 张照片。
4. 提交后阶段变为“待管家验收”。切换“管家”，可以填写原因“退回继续施工”，也可以选择“提交主业主验收”。
5. 管家提交时须逐项勾选全部 5 项，填写现场验收说明，并重新模拟拍摄至少 3 张照片；提交后阶段变为“待主业主验收”。
6. 切换“主业主”后可通过或不通过。主业主不通过后，由管家安排师傅继续施工，师傅再次申请。
7. 防水流程可切换“吴师傅 · 防水工”申请，再切换管家分 5 个节点记录：第一遍防水及第一次闭水开始、第一次闭水结束、卫生间回填、第二遍防水及第二次闭水开始、第二次闭水结束。每个节点分别模拟拍摄至少 3 张照片；第一次闭水至少 72 小时，第二次闭水至少 48 小时。5 个节点完成后勾选最终清单并提交，第 5 节点照片自动复用，不重复拍摄。
8. “竣工验收与交付”不经过师傅申请，由管家直接提交。前 10 个阶段、全部问题或材料批次未完成时，页面会列出阻止原因。

### 2. 问题处理结束后，才能通过阶段验收

1. 选择“主业主”，进入“阶段验收 → 水电隐蔽工程”。
2. 只要还有未结束问题，“确认阶段验收通过”应为禁用状态；页面提示剩余问题数量。
3. 点击问题查看处理情况。需要整改的事项，经管家安排、师傅整改后由主业主验收；无需整改的说明也须由主业主认可。
4. 全部关联问题处理结束后，回到水电阶段，“确认阶段验收通过”才可点击；主业主确认后阶段通过，不自动通过。
5. 如果此前按旧规则带问题通过，刷新新版本会恢复为待验收，并在详情保留旧验收历史。已解决的问题不会变回未解决。请刷新其他已打开的原型标签页后再操作。

### 3. 师傅发布 → 管家检查 → 整改 → 业主验收

1. 切换“师傅”，选择张师傅，发布一条今天的现场记录。施工位置可以点击固定选项并支持多选，也可以在输入框自由修改；使用“拍摄照片”选择 3 张照片，或使用“录制视频”选择 1 段视频，电脑端以文件选择模拟相机。“本次施工内容”和“计划完成日期”只读显示，由管家在施工安排中维护。
2. 切换“主业主”或其他工种师傅，应立即能看到该记录。
3. 切换“管家”，进入“主卫管道固定点待补充”，安排张师傅整改，填写要求和日期。
4. 切换张师傅，打开该问题。这里既可模拟现场拍摄，也可使用“上传照片／上传视频”，提供至少一项媒体后申请验收。
5. 切换主业主，验收通过，或填写原因不通过；不通过后问题回到管家继续跟进。

### 4. 材料每批单独确认

1. 主业主打开“材料进场”，原有两批会显示“待现场补拍”，确认按钮不可用。
2. 切换“管家”，打开第一批，选择“补拍现场影像”，模拟拍摄至少 3 张照片和 1 段视频；登记或更正批次时，“使用位置”可用固定按钮多选，也可自由输入。
3. 切换主业主，只确认第一批；第二批应仍保持待现场补拍。
4. 对已具备现场影像的待确认批次选择“材料有问题”，填写原因。管家重新提交时必须提供最新 3 张现场照片和 1 段现场视频。
5. 切换家庭成员，应可以查看，但没有正式确认按钮。

### 5. 设计师维护设计资料

1. 切换“设计师”，首页应显示“设计资料协作”和“添加设计资料”。
2. 打开“图纸”，可新增普通效果图、施工图 PDF／DWG 或 720°全景链接。“对应空间”可用 13 个固定按钮多选，也可自由填写玄关等其他位置。施工图可只选 PDF、只选 DWG，也可以两种同时选择；同名资料的新版本设为当前资料，旧版本继续保留。
3. 设计师可查看施工进度、问题、阶段和材料，但不能安排施工、安排整改、确认材料或执行业主验收。

### 6. 管家发布现场巡检

1. 切换“管家”，在首页或“进度”中点击“发布现场巡检”。
2. 选择关联施工阶段和施工位置，填写巡检情况；用“拍摄照片”模拟选择至少 3 张照片，或用“录制视频”选择 1 段视频。
3. 发布后记录立即对项目成员可见，并显示“管家现场巡检”和关联阶段。
4. 切换对应工种师傅查看当天状态：管家巡检只作补充，仍需师傅发布自己的施工记录才能显示“今日已更新”。

### 7. 增项登记 → 确认 → 施工 → 验收

1. 切换“管家”，从首页进入“增项变更”，点击“登记增项”。填写名称、位置、阶段、原因、施工内容、材料费、人工费和延期天数，并至少提供现场照片、报价单、图纸或说明文件中的一种依据。
2. 切换“主业主”，打开待确认增项。可以确认价格与工期，也可以填写原因拒绝；被拒绝后管家可建立新版本重新提交，旧版本继续保留。
3. 确认后切回管家，安排责任师傅和施工日期。切换到该师傅，从“施工安排”打开已分配的施工任务，并现场拍摄至少 3 张照片申请验收；师傅端不单列“增项变更”，也不显示金额和版本。
4. 管家检查后可以退回继续施工，或另拍至少 3 张现场照片提交主业主；主业主最终确认完成或退回处理。
5. 未确认增项可由管家撤回；已确认未开工时由管家申请、主业主确认取消；已经施工时须记录工程量、实际费用和现场情况，由主业主确认终止结算。
6. 家庭成员默认看不到增项金额，主业主可在“人员”中授权；设计师金额权限由负责人授权；师傅始终不显示金额。

## 其他可体验内容

- 管家：调整工种日期、停工日、主要上传责任人；发布现场巡检；审核包括设计师在内的模拟成员申请；登记材料批次；登记、安排和验收增项变更。
- 师傅：查看其他工种进度、反馈最早可进场日期；管家协调后才改变实际施工安排。
- 设计师：维护效果图、PDF／DWG 施工图和全景链接，查看参与项目的进展；施工图每个版本至少选择 PDF 或 DWG 中的一种；不处理施工安排与正式确认。
- 负责人：创建项目并指定管家；选择本机效果图、PDF／DWG，或添加全景链接。
- 图纸：切换效果图、施工图、720°全景。示例 PDF／DWG 只是资料卡，未附虚构文件。实际文件需由你选择。
- 主要流程使用“云栖花园”示例项目；其他项目用于展示负责人项目列表与管家分配。六种身份是固定演示视角，不是实际账号登录。
- 正式小程序会根据微信账号自动识别成员身份和管家配置的工种，不显示供师傅自由切换岗位的下拉框；当前控件只用于一台电脑模拟多个账号。
- “恢复演示数据”可以回到初始状态；小屏幕入口在“本地原型 · 演示说明与重置”中。
- 主业主通过第 11 阶段后，项目转为“已完工”；施工、问题、材料和验收历史只读保留。此后主业主或家庭成员可建立独立“售后／保修问题”，不会改变竣工结论。

## 独立试用竣工验收、完工记录和售后

原项目仍有未通过的阶段和待确认材料，不能直接竣工。请从原型左侧的“打开竣工试用副本 ↗”进入新标签页；也可直接打开 http://127.0.0.1:4173/?trial=final#home 。副本从原项目当前记录复制一次，单独保存在本浏览器，原项目记录不受试用操作影响。页面会醒目标明“竣工流程试用副本”，并列出原项目当时未满足的门槛。副本**仅为试用流程而模拟放行门槛**，验收结果不代表实际施工已经完成。

1. 在副本中切换“管家”，进入“阶段验收 → 竣工验收与交付”，查看原项目尚未满足的门槛，再点击“提交竣工验收”。
2. 试用时逐项勾选 9 项清单，填写模拟说明，用“拍摄照片”选择至少 3 张示例图片，然后提交。电脑浏览器以文件选择模拟现场相机。
3. 切换“主业主”，回到同一阶段，确认竣工验收与交付；检查项目显示“已完工”，之前的施工、问题、材料和验收记录仍可查看，但不能继续修改。
4. 在“待办 → 售后／保修”中新建一条模拟售后问题；切换“管家”记录处理进展，再切换“主业主”确认处理完成。核对项目仍为“已完工”，原竣工结论不变。
5. 想重新试用时，只在副本中点“重新开始竣工试用”。“返回原项目 ↗”可查看真实演示状态，仍应显示原先的竣工门槛。

这里的“归档”只演示完工状态、施工记录只读和售后记录分开管理。5 年保存、分层存储及 ZIP 导出仍是正式小程序的已确认需求，尚未在本地原型实现。

## 当前边界

- 施工、人员、材料数据均为虚构示例；用户提供的设计海报和全景链接单独标注为样例。
- 数据只在本浏览器保存，角色切换演示同一份数据，不是多台手机同步。
- 文件只在本机当前页面预览，刷新后保留文件名称，需重新选择文件才能再看。演示单次 30MB 限制不是正式小程序上传规格。
- 施工记录、阶段验收和材料页面只显示拍摄按钮；电脑浏览器会用文件选择模拟拍照／录像。普通阶段中，师傅申请和管家提交各自必须选择至少 3 张现场照片；防水阶段管家改为 5 个节点分别拍摄至少 3 张照片，并复用第 5 节点照片完成最终提交。视频只能补充。提出问题和问题整改同时保留拍摄与上传入口；增项登记可拍现场照片，也可选择报价单或图纸。
- 照片预览会生成包含拍摄时间或上传时间的水印版本；视频只显示录制或上传时间。真实微信相机权限和手机拍摄效果需等正式小程序开发后验证。
- DWG 配套保存，不提供在线 CAD 预览或编辑。
- 全景在新页面打开用户已核验的原作品；微信小程序内嵌、跳转和文件真机效果尚未验证。
- 尚无正式登录、云存储、微信消息、真实邀请链接／二维码或上线服务。
- 表单字段、页面组织和具体操作文案供本轮试用评审，不自动成为已确认的最终产品规则。
