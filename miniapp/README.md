# 微信小程序本地页面试用

本目录是主项目的微信原生小程序工程。首页保留已部署的 `connectionCheck` 云连接测试，同时提供四类本地页面：项目列表、施工安排、师傅现场记录、项目成员查看。页面中的项目、地址和成员都标为虚构示例；施工安排和记录只写入当前小程序的本机缓存，不写入 `cloud1` 数据库，也不在不同手机之间同步。

## 在微信开发者工具中打开

1. 打开已安装的微信开发者工具，选择主项目目录 `C:\Users\30591\Documents\ChatGPT\装修进度验收APP\miniapp`。它包含现有的 `project.config.json`，无需新建项目或云环境。
2. 点击“编译”。首页应同时看到“测试云连接”、虚构示例提示、“试用身份”和“示例甲 · 晴川居”。若仍只显示旧的“小程序工程已建立”，核对工具打开的项目路径，并重新编译一次。
3. 云连接按钮仍调用原有 `connectionCheck`，只验证连接；无需每次试用页面都点击。已验证的模拟器、手机连接结果记录在 [进展与待办](../docs/进展与待办.md)，页面数据保存与微信身份权限尚未接入云端。

## 建议按顺序试用

1. 首页默认选中“示例管家”。进入“示例甲 · 晴川居”，今天应有水电和泥瓦两个施工工种。点“项目成员”，可看到木工已加入但尚未进场；返回项目后，在“施工安排”选择明天，水电显示休息／停工，不要求当天更新。
2. 管家点“新增施工安排”可填写工种、阶段、主要上传责任人、起止日期、本次施工内容、预计完成日期，并添加休息／停工日；点现有卡片的“调整安排”可改责任人或日期，旧记录仍保留发布时的安排快照。
3. 返回首页，将“试用身份”改为“示例水电师傅甲”，进入甲项目，点“发布今日现场记录”。项目与工种自动带入；“本次施工内容”和“预计完成日期”只读。位置有 13 个快捷多选按钮，也可在输入框补充。
4. 填写**虚构**现场说明。默认“模拟拍摄（电脑试用）”：先拍两张模拟照片并尝试发布，应提示影像不足；补第 3 张后可发布。也可改用一段固定 15 秒的模拟视频。模拟影像仅为占位卡，没有真实照片或视频文件。
5. 返回首页切换“示例主业主”，进入同一项目的“现场记录”，应立即看到刚发布的本机记录。记录按时间排列，可按日期查看。切换泥瓦师傅、设计师或家人可查看同项目普通进度；未加入、已退出及乙项目账号看不到甲项目。这里的账号选择与访问判断只用于本地试用，不能证明正式权限安全。

本地数据使用独立缓存键 `renovation-native-local-v1`。重启同一小程序后仍尝试读取该设备的记录；清理小程序缓存会丢失本地数据。换天后可在首页“重置本地虚构示例”重新生成今天的安排；重置前会弹出确认。未发布草稿在离开页面后不保留。

## 影像与权限边界

- “设备相机（待真机核验）”入口只请求相机拍摄，代码限制最多 9 张照片、视频最长 60 秒；照片请求压缩。设备授权、照片压缩效果、视频播放及本机文件重开尚待真机验证。
- 相机文件会先尝试复制到小程序本机文件目录；全部保存成功后才在本机写入记录。失败时当前页面保留表单与影像供重试。本流程不上传云存储。
- 页面显示本机记录的拍摄时间；**照片水印尚未烧录**，视频压缩、可信拍摄时间、影像更正与服务端来源校验尚未实现。请勿将本地记录用于真实施工取证。
- “试用身份”只是单设备演示开关。正式微信账号识别、项目成员权限及业务数据保存须由后续可信云端接口实施和验证。

## 本轮核验

- 19 项 Node 本地测试通过，覆盖日期、同日多工种、角色模拟、三照／一视频、9 张照片和 60 秒边界、失败重试、重复提交、安排阶段默认值及首页云连接逻辑的模拟响应。
- JavaScript、JSON、5 个页面路由通过静态检查；本机微信开发者工具编译器验证 5 个 WXML、6 个 WXSS 通过。
- 本轮在主项目开发者工具模拟器中实际看到首页、项目安排、项目成员、安排表单及师傅发布页；原有“测试云连接”按钮在合并后再次调用成功。自动操作发布页时，工具返回一次 `APPID_ERROR / aborted`，因此助手没有完成模拟器发布和业主查看的自动核验。用户随后反馈上述人工核验均无问题，包括师傅模拟发布后由主业主查看的本地试用流程；此结论来自用户人工确认，不等同于助手自动测试或真机相机核验。
- 没有新建云环境、部署函数、购买服务、录入真实客户资料、上传体验版或正式发布。

在主项目根目录可复核：

```powershell
node --test miniapp/tests/*.test.cjs
node miniapp/scripts/check.cjs 'D:\微信web开发者工具\resources\app.asar.unpacked\node_modules\wcc-exec'
git diff --check
```

第二条命令使用本机已有的微信编译器；如果安装位置不同，传入实际 `wcc-exec` 目录。省略此参数时只检查 JS、JSON 和页面路由，不能算模板编译通过。

页面入口：`miniprogram/pages/index/index`；进入项目后可访问施工安排、现场记录和项目成员。代码中的本地示例及校验位于 `miniprogram/utils/`。当前业务规则以 [需求与业务规则](../docs/需求与业务规则.md) 为准，云端实施范围仍以 [正式版数据与权限方案](../docs/正式版数据与权限方案.md) 的讨论稿另行确认。
